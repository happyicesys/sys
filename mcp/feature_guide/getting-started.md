# Getting started
The main ideas in ConnectVend, where each menu is, and which guide topic answers which question.

## The main ideas

- **Operator**: the company that runs the machines. Users, machines, sites and products belong to an operator.
- **Site**: the place where a machine stands (the customer or location). Contacts, location fee and contract live on the Site.
- **Machine**: one vending machine, smart freezer or smart chiller. A machine is bound to one Site at a time; you can unbind it and bind it to another Site.
- **Channel**: one slot or lane in a machine, with a channel code. On smart freezers and chillers a channel is a product position; stock is kept per product.
- **Product**: an item you sell, with its photo, cost and prices.
- **Mapping**: the planogram, i.e. which product goes into which channel. One mapping can be shared by many machines; a change to it reaches every machine using it.
- **Job** (ops job): a driver's day of work, i.e. the machines to visit, what to pick from the warehouse, what to stock in, in which order.
- **Transaction**: one sale (or attempted sale) on a machine, with its payment method and dispense result.
- **UI Setting**: the touchscreen settings for a group of machines: banners, campaigns, refund or complaint button, welcome screen.
- What you see depends on your role. If a menu or button in this guide is missing for you, ask your ConnectVend administrator.

## Where to find things

- **Dashboards**: performance at a glance and machine health → topic `dashboards`
- **Operations ▸ Dashboard**: the daily machine list with stock, errors, online status, temperature → topic `operations`
- **Transactions**: sales, refunds, settlements, AI Recognition for smart freezers → topic `transactions`
- **Daily Jobs**: driver jobs, stock counts, service notices → topic `daily-jobs`
- **Machine Management**: machine settings, binding to a site, Happy Hour, UI Setting, app updates → topic `machine-management`
- **Site Management**: sites, commission, site settlement → topic `site-management`
- **Product Management**: products, mappings, warehouse stock → topic `product-management`
- **Campaign Management**: promotions and vouchers → topic `campaigns`
- **Data Management**: reference lists such as SIM cards, card terminals, routes, banks → topic `data-management`
- **Report**: sales, GP and stock reports → topic `reports`
- **Admin**: operators, users, Claude access, translations, tutorials → topic `admin`
- **Grab**: GrabFood stores, orders and menus (Singapore only) → topic `grab`

## Common questions and where they are answered

- Add a new machine, or move a machine to another site → `machine-management` (Machines Settings) and `site-management` (Sites)
- Add a new product, or change a price → `product-management` (Products)
- Put a product into a machine / change what a machine sells → `product-management` (Mappings)
- Plan a driver's refill, stock in, route order → `daily-jobs` (Jobs)
- Why a machine shows offline, or has errors → `operations` (Dashboard) and `dashboards` (Machine Health)
- Find a sale, check if it was paid or dispensed → `transactions` (All Transactions)
- Handle a customer's refund request → `transactions` (Refund Requests)
- Run a Happy Hour discount → `machine-management` (Happy Hour Campaign)
- Make a voucher code → `campaigns` (Voucher)
- Change the refund / complaint button on the screen → `machine-management` (UI Setting)
- Monthly sales and profit per machine or product → `reports`
- Add a user, give access, reset a password → `admin` (Users)
- Change the words shown on a screen in another language → `admin` (Translations)
