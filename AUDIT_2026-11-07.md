# mark1 code audit: 2026-10-17 → 2026-11-07, plus a page and API speed pass

**Scope:** everything on `main` since the last audit (`AUDIT_2026-10-17.md`, `46bc0a333f`) up to `51f5a96733`. That is 286 commits and about 76k added lines. Happy Hour internals were audited on 10-30 (`HAPPY_HOUR_AUDIT_2026-10-30.md`), and the controller-silence work on 11-07 (`CONTROLLER_SILENCE_AUDIT_2026-11-07.md`); those areas are not repeated here. Brian also asked for every page and the machine API to load faster and leaner, without breaking anything.

**Method:**
- Six read-only reviews, one per area: freezer / AI / T05 (`SF2-xx`), Grab (`GRAB-xx`), Ops Dashboard / core (`CORE2-xx`), access / i18n / payments (`ACC-xx`), Vue (`UI2-xx`), and page + API speed (`PERF-xx`).
- Prod checks used the read-only MCP: `information_schema`, row counts and small aggregates. EXPLAIN is blocked there, so no query plans were captured.
- Each fix below was applied by hand, then re-checked against the source.

**Before and after:** the full suite ran before any change: 2,458 passed, 2 failed. Both failures came from the worktree's copied `vendor/` missing the Anthropic SDK; `composer install` fixed that. After the fixes it ran again on a private DB (result in the commit message). Built assets were loaded in a local preview with no console errors.

## Verdict

| Lens | Grade | In one line |
|---|---|---|
| Best practice | **B−** | Money paths are written ahead, locked and re-checked. The gaps found are at the edges: a lock taken after the read, a refund's two writes not in one transaction, a translation editor that could store script, and unauthenticated Grab orders (env switch). |
| OOP / design | **C** | New services stay small and single-writer. But `FreezerRecognitionController` (1,122 lines) now holds business rules, `CustomerIndex.vue` is 5,834 lines, money formatters went from 14 to ~25, and `app()` lookups keep being added to controllers. |
| Performance | **B−** | New tables are indexed and pruned (Grab Errors). The costs are repeated identical work: eager props on pages that reload part of themselves, an unused 60 KB route map in every response, whole 28 KB `vends` rows for a heartbeat, and two unbounded log tables. |
