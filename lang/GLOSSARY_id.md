# Bahasa Indonesia glossary (mark1 UI)

Draft 2026-10-30, reviewed 2026-10-30 (meaning, grammar and term consistency across all texts), for superadmin / admin review. These are the words every page reuses, so each English term
has ONE Indonesian wording everywhere. Change a wording on **Admin → Translations** (or with **Edit wording**
on any page); tell the developers when a GLOSSARY term changes so new pages use the new word too.

Style: plain, short office Indonesian, the way ops staff talk — "Anda" when addressing the user, buttons as
short verbs (Simpan, Cari, Hapus). Common English loan words that Indonesian ops already use are kept
(Refund, Settlement, Online, Error, Upload is NOT kept — Unggah).

Kept in English on purpose: APK, VMC, SKU, QR, NETS, PayNow, Omise, Grab, Nayax, HID, IMEI, SIM, GP, OTA,
MCP, CMS, ID, Happy Hour, Smart Freezer, Smart Chiller, CityBox, and product / site / machine names (data,
never translated).
