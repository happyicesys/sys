# Simplified Chinese glossary (mark1 UI)

Draft 2026-10-26, for superadmin / admin review. These are the words every page reuses, so each English term
has ONE Chinese wording everywhere. Change a wording on **Admin → Translations** (or with **Edit wording**
on any page); tell the developers when a GLOSSARY term changes so new pages use the new word too.

Kept in English on purpose: APK, VMC, SKU, QR, NETS, PayNow, Omise, Grab, Nayax, HID, IMEI, SIM, GP, OTA,
